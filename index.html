Todo JSON Storage Module

This is a Node.js module for reading/writing todos to todos.json.

Module Functions

  • readTodos(filePath?) - Returns Promise<Array>
  • writeTodos(todos, filePath?) - Returns Promise<void>
  • addTodo(todo, filePath?) - Returns Promise<Object>
  • updateTodo(id, updates, filePath?) - Returns Promise<Object|null>
  • deleteTodo(id, filePath?) - Returns Promise<boolean>

Usage

const { readTodos, writeTodos, addTodo, updateTodo, deleteTodo } = require('./src/store');

// Read all todos
const todos = await readTodos();

// Add a new todo
await addTodo({ id: Date.now(), title: 'Learn Node.js', completed: false });

// Update a todo
await updateTodo(id, { completed: true });

// Delete a todo
await deleteTodo(id);
